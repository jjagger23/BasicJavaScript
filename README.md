# BasicJavaScript

This project demonstrates foundational JavaScript concepts including functions, loops, arrays, objects, form interaction, and dynamic style changes.

The page allows users to:

Increment and decrement a counter

Generate numbers using a for loop

Display odd numbers using conditional repetition

Create and log an array of multiples of 5 in reverse order

Work with JavaScript objects and populate form fields

Dynamically change the color of a paragraph using button controls

The JavaScript logic is contained in script.js and is linked to the provided HTML file.
Console output (for the array and object exercises) can be viewed using browser developer tools.

This project was completed as part of a JavaScript fundamentals assignment.
